## Контроль тестовых данных

- [ ] Использованы только четыре согласованных тестовых аккаунта.
- [ ] Фото не содержит лиц, номеров, документов или чужих персональных данных.
- [ ] Выплата проведена на контролируемый тестовый аккаунт и минимальную сумму.
- [ ] Записаны `task_id`, `assignment_id`, `withdrawal_id`, OPS message link и
  внешний номер только тестовой операции.
- [ ] Тестовые задачи закрыты/отменены, активные резервы отсутствуют.
- [ ] Тестовые сообщения и маркеры удалены из Telegram после фиксации доказательств.
- [ ] Секреты и полный ID получателя отсутствуют в отчёте и скриншотах.
- [ ] После cleanup readiness снова PASS, dead queues равны нулю.
