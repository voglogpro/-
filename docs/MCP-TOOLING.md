# MCP и инструменты проверки

Для проекта выбран минимальный набор с понятным владельцем и ограниченными правами.

| Инструмент | Назначение | Решение |
|---|---|---|
| Figma MCP | дизайн-система, светлая/тёмная темы, макеты ключевых экранов | использовать для дизайн-итераций |
| Microsoft Playwright MCP `0.0.78` | браузерные, мобильные и accessibility-проверки | установлен локально, headless + isolated |
| GitHub MCP | issues, PR и автоматизация репозитория | пока не подключать: локального Git достаточно, токен не выдаём без необходимости |

Playwright закреплён на конкретной версии и запускается без постоянного browser profile, без unrestricted file access и с заблокированными service workers. Любой новый MCP сначала проверяется по официальному репозиторию, лицензии, требуемым секретам и области доступа.

MCP не заменяют автоматические тесты, code review и ручную проверку внутри настоящего Telegram на Android, iOS и Desktop.
