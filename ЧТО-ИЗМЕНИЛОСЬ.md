## 1. Твой доступ

В `main.py` зашито:

```python
OWNER_IDS = {7785586524}
ADMIN_IDS = _parse_ids(os.getenv("ADMIN_IDS", "")) | OWNER_IDS
```

Роль ответственного выдаётся сразу при открытии приложения.

**Кнопку регистрации ответственного убрал полностью** — и переключатель
на экране заявки, и поле пароля в профиле. В приложении больше нет ни
одного поля ввода пароля. Роли теперь раздаёшь ты сам, через `Команда`.

Из этого следует одно: единственный вход для тебя — твой Telegram ID.
Если когда-нибудь сменишь аккаунт, впиши новый ID в `OWNER_IDS` или в
переменную `ADMIN_IDS` на хостинге **до** того, как потеряешь доступ к
старому. Метод `/api/admin/login` на сервере остался, но не используется
интерфейсом — если понадобится, верну кнопку за пять минут.

## 2. Роли участников

`Модерация → Команда`. У каждого участника видна текущая роль и кнопка
`Роль` — открывается выбор из трёх:

| Роль | Что может |
|---|---|
| 🌿 Помощник | берёт задания, получает бибибонусы |
| 🚲 Сотрудник | то же, плюс пометка «штатный» в команде |
| 🛡️ Ответственный | заявки, задания, награды, обмены |

Роль меняется мгновенно, участник получает сообщение от бота. Три правила
защиты, чтобы не сломать себе доступ:

- свою роль сменить нельзя — только через другого ответственного;
- последнего ответственного понизить нельзя, иначе заявки повиснут навсегда;
- роль выдаётся только одобренному участнику — сначала прими заявку.

Заодно: персональное задание теперь можно назначить и ответственному
(раньше он выпадал из списка исполнителей).

## 3. Дизайн

Белый лист, светло-серые карточки, зелёный только акцентом.

- Фон белый, карточки `#F4F5F4`, скругление 24, без рамок и теней — плоско.
- Зелёный появляется ровно в пяти местах: заполнение шкал, число бонусов,
  чипы наград, активная вкладка, главная кнопка. Больше нигде.
- Зелёных заливок во всю плашку нет — от них отказался, как ты и просил.
- Один мотив на весь интерфейс: любой прогресс это **шкала заряда** с
  бегущим разрядом. Уровень доверия, реферальные ступени, сколько осталось
  до обмена — одной визуальной логикой.
- Бибибонус измеряется молнией ⚡.

**Команда стала компактной.** Раньше на каждого человека уходило полэкрана:
имя переносилось на две строки, четыре кнопки разъезжались в два ряда.
Теперь участник — одна строка: значок уровня, имя, под ним роль · уровень ·
задания, справа баланс. Тап по строке открывает шторку с четырьмя
действиями: начислить, списать, награда, роль. Список из двадцати человек
теперь читается так же легко, как из двух.

Ряд подвкладок модерации получил мягкий край справа — видно, что он
листается, а не обрезан.

**Анимации не тронуты.** Все восемь keyframes на месте: въезд карточек,
разряд по шкале, вспышка по карточке задания, подскок счётчика бонусов,
подпрыгивание медалей, пульс следующей ступени, шторки, затемнение.

Про оптимизацию: ни одного внешнего шрифта, ни одной библиотеки, ни одной
картинки — только тег Telegram SDK. Всё движение на `transform` и
`opacity`, то есть на GPU и без перерисовки страницы.
`prefers-reduced-motion` уважается.

## 3.1. Реферальная ссылка и подписка на канал

Ник бота по умолчанию — `bbbikefan`, ссылка собирается сама:

```
https://t.me/bbbikefan?start=ref_<твой telegram id>
```

**Новое: реферал засчитывается по подписке на канал.** Настрой на хостинге:

```
REQUIRED_CHAT=@имя_твоего_канала
```

Принимается `@username`, полная ссылка или числовой id вида
`-1001234567890`. Кнопку «Подписаться» можно переопределить переменной
`REQUIRED_CHAT_URL`.

⚠️ **Бота нужно сделать администратором канала.** Без прав администратора
Telegram не даст проверить подписку — метод `getChatMember` вернёт ошибку.

Как это работает:

1. Друг открывает `https://t.me/bbbikefan?start=ref_<твой id>`.
2. Бот сохраняет, кто его пригласил, и просит подписаться — с кнопками
   «Подписаться на канал» и «Я подписался».
3. Друг подписывается и жмёт «Я подписался» → бот проверяет через Telegram
   → **+1 в твоём прогресс-баре**, тебе приходит уведомление.
4. Ту же кнопку можно нажать внутри приложения: у приглашённого на вкладке
   «Задания» появляется карточка «Подпишись на канал».

Защита от накрутки:

- без реальной подписки не засчитывает — проверка идёт у Telegram,
  а не на слово;
- повторные нажатия не дают второй +1 (уникальный флаг в базе);
- пришедший без ссылки получает честное «засчитывать нечего»;
- если бот не админ в канале — понятная ошибка вместо 500, а реферал
  засчитается по старому правилу, при одобрении заявки в команду.

Старое правило никуда не делось: **одобрение в команду тоже даёт +1**,
даже если канал не настроен. У всех, кто был одобрен до обновления,
прогресс сохранится — миграция проставляет флаг задним числом.

Ступени прежние: 5 друзей → 50, 25 → 500, 50 → 1500, 100 → 4000.
Каждая выплачивается ровно один раз.

## 4. Награды (из прошлой версии)

`Модерация → 🏅 Награды`. Свой каталог: значок, название, за что, бонус,
плюс переключатели «много раз / один раз» и «показывать в каталоге».
Разовая награда не выдастся дважды — это защищено уникальным индексом в
базе, а не проверкой в коде. Есть `Снять`: бонус вернётся и не уведёт
баланс в минус. В `Команде` у каждого кнопка 🏅.

Восемь наград уже засеяно: ⚡ Молния, 🛠 Мастер, 🌙 Ночная смена,
🏅 Спасатель, 📸 Глаз-алмаз, 🤝 Наставник, 👑 Легенда месяца,
🌱 Первое задание. Твои правки при следующем деплое не перезапишутся.

## 5. Что было починено попутно

- **WAL для SQLite** — без него параллельные «Взять задание» упирались в
  блокировку и отдавали 500. Плюс таймаут ожидания 15 секунд.
- **Обработчик ошибок на весь API** — любой сбой отдаёт JSON, а не
  трейсбек с пустой «Ошибкой» на экране.
- **Уведомления в фоне** — раньше рассылка админам шла внутри HTTP-запроса.
- **Валидация ID** — `task_id: "abc"` больше не превращается в 500.
- **Отклонённого можно вернуть** — раньше `reject` ставил `blocked`
  навсегда, без правки базы человека было не восстановить.
- **`prompt()` убран** — в Telegram WebView он работает не на всех
  клиентах, кнопка «Готово» могла молча не срабатывать. Вместо него
  своя шторка ввода.
- **Тупик со входом** — форма пароля жила внутри блока регистрации и
  исчезала после отправки заявки.
